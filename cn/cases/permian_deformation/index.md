# 基于时序InSAR的Permian盆地油气开发相关地表形变监测

累积形变结果显示，Pecos地区及其周边存在显著的沉降信号。自2014年11月至2017年1月期间，该区域已出现超过5厘米的累计视线向沉降；至2019年1月，累计沉降进一步增大，局部区域超过10厘米，且覆盖区域扩大了约四倍。该结果与Staniewicz等（2020）利用Sentinel-1数据获得的观测结果基本一致。其研究指出，Pecos以南约15 km区域在2014年至2019年期间累计沉降达到约13 cm，并表现出持续增强的形变趋势。本研究获得的沉降中心位置及形变量级与前人研究具有较好的一致性，表明Pecos地区长期存在显著的地表沉降过程。

为减弱残余大气延迟对InSAR形变结果的影响，本研究采用了基于基于中位数绝对偏差的异常干涉图识别与剔除方法。该方法利用统计指标识别受强对流天气、热浪等异常大气条件影响较大的干涉图，并将其从后续叠加计算中剔除。由于大气噪声通常表现为长波长空间误差，异常干涉图会在累积形变场中产生大尺度伪信号。经过异常值剔除后，形变场中的长波长条带和背景起伏明显减弱，沉降中心及其空间分布特征更加清晰，说明该方法能够有效降低残余大气误差，提高形变结果的可靠性。

升轨与降轨结果在Pecos南部主要沉降区表现出较好的一致性，二者均显示出明显的沉降中心和相近的形变量级，表明该区域形变以垂向运动为主。然而，在Pecos附近及其北侧区域，升轨与降轨观测结果存在明显差异。由于升轨和降轨对东西向位移具有不同的观测敏感性，水平运动会在两种观测几何下产生不同的LOS形变响应。因此，本研究中观察到的升降轨差异很可能反映了该区域同时存在垂向沉降和水平位移，说明地表形变并非简单的一维压实过程，而可能与断层活动及储层压实共同作用有关。其中，油气开采导致的孔隙压力下降会引起储层压实，而应力场变化则可能诱发正断层活动，从而产生额外的垂向和水平形变。

Pecos地区持续增强的沉降信号可能与Permian Basin近年来快速发展的油气开采活动有关。本区域的形变速率在2017年至2019年期间明显增加，与同期非常规油气产量的快速增长相对应。本研究观测到的2017年以后沉降加速现象，很可能反映了该区域油气开发活动增强及其相关地质力学响应的综合影响。
